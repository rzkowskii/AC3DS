AC-3DS builder

Makes the one file that puts AssaultCube on your New Nintendo 3DS, New 3DS XL or New 2DS XL. It joins the official AssaultCube download with the AC-3DS engine.

Nothing is uploaded. The work happens inside this browser tab, on your own computer. The page loads only its own files and sends nothing anywhere.

  1. Get AssaultCube

    Open the official AssaultCube download page and download the Linux package of version 1.3.0.2. The file is named exactly:

    AssaultCube_v1.3.0.2_LockdownEdition_RC1.tar.bz2 (52 MB)

    This is the right file on Windows and macOS too. Do not unpack it. The Windows installer (.exe) and the Mac disk image (.dmg) will not work here. Direct link to the same file on AssaultCube's GitHub releases.

  4. Save the file

    The finished file appears here after the build. It is about 64 MB.

    Save assaultcube.3dsx

  5. Copy it to the SD card

    Put the saved file on the console's SD card as:

    /3ds/assaultcube/assaultcube.3dsx

    Create the assaultcube folder if it is not there, and replace any older assaultcube.3dsx. The right file is the one of about 64 MB; if your browser saved it as assaultcube (1).3dsx, rename it. When a new AC-3DS release comes out, build again with it: copying the release's small file over this one removes the game data. Then start AC-3DS0 from the Homebrew Launcher. Your settings stay in /3ds/assaultcube/profile/.

Questions

What do I need on the console?

A New Nintendo 3DS, New 3DS XL or New 2DS XL that can run the Homebrew Launcher (for example with Luma3DS). The original 3DS and 2DS do not have enough memory. Sound needs the file /3ds/dspfirm.cdc on the SD card, which you make once from your own console (Luma3DS: hold L + Down + Select, then Miscellaneous options, Dump DSP firmware). Without it the game still runs, silently.

Can it make a .cia or a .3ds instead?

No. An installable .cia and a .3ds cartridge image keep their data in a signed, hashed container that has to be built with a separate packaging program, which a web page cannot run. A .3dsx with the game data attached does the same job from the Homebrew Launcher and is one file.

It says my file is the wrong one.

The page accepts only the unchanged official file AssaultCube_v1.3.0.2_LockdownEdition_RC1.tar.bz2, 52,071,427 bytes. It checks the file's size and its SHA-256 fingerprint:

9b3118e7929253f0114fa06cad8310faab646d177b4660406011152f34086b55

If your browser unpacked the download or it was cut short, download it again. Other versions of AssaultCube are not supported.

Is anything sent over the internet?

No. The page reads the files you give it in this tab and builds the result in memory. It has no analytics and is blocked by its own security policy from contacting any other site. You can save the page's folder and use it offline.

Can I do this without a browser?

Yes. The AC-3DS repository has scripts/make-3dsx.py, which needs only Python 3 and writes the same file byte for byte:

python3 make-3dsx.py AssaultCube_v1.3.0.2_LockdownEdition_RC1.tar.bz2 assaultcube.3dsx out/assaultcube.3dsx
